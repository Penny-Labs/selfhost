# Changelog

## 1.0.0-beta.1

- Pins the Penny API and PennyOS web beta images.
- Supports startup activation from an existing Kubernetes Secret.
- Persists the install identity and encrypted runtime lease cache on a PVC.
- Enables the outbound managed-command websocket and managed sync provider.
- Keeps local Base functionality independent from hosted entitlement state.

This is a beta release. Stripe billing is test-mode only and the chart is not a
claim of general availability or completed public legal/security review.
